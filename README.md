This application provides a simple, highly customizable way to overlay an image across the operator’s display when they leave the console—helping communicate console status, prevent unintended interaction, and keep the workspace visually appropriate during live theatrical and concert productions.\
Designed specifically for production environments, the application can display custom graphics, logos, signage, artwork, or other images whenever the operator steps away. When the operator returns, the overlay can automatically disappear, restoring the normal console view.

Features include:
  Custom overlay images — Use your own artwork, logos, signage, or production graphics.
  Automatic activation — The overlay appears when the operator walks away from the console.
  Automatic dismissal — Returning to the console restores the normal display.
  Full-screen presentation — Cover the entire display to clearly communicate the console's unattended state.
  Operator-friendly behavior — Designed to stay out of the way during normal operation.
  Production-focused design — Built with live theatrical and concert workflows in mind.
  Flexible visual communication — Use anything from a simple "Please Do Not Touch" message to elaborate production branding or backstage graphics.

Full-Screen Overlay
The overlay is presented above other applications, providing a clear visual indication that the workstation is unattended. The display can be configured for the intended production environment and monitor configuration.

Immediate Return to Operation
Keyboard or mouse activity dismisses the overlay and returns the operator to the underlying workstation. This allows the application to remain active throughout a production without interrupting normal console operation.
